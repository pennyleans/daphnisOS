# Contributing

Daphnis is experimental. Useful bug reports describe what happened, what you
expected, the release version, and the steps needed to reproduce it. Include
whether you used QEMU or physical hardware, along with the relevant machine
configuration. Please leave passwords and other private data out of logs.

Report bugs and propose changes through this repository's issues and pull
requests. Keep patches focused and explain how you checked them. Development
and integration happen in a separate repository; accepted patches are brought
into that tree and checked before a later public release snapshot.

The public repository does not run contributed code on self-hosted CI runners.
The build and test scripts are included for local use. The user guide describes
release images separately from developer and test images.
