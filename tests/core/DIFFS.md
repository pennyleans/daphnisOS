# Deliberate differences from busybox

The native core set agrees with busybox 1.36.1 on every case of `tests/core/*.cases` except the rows below
(docs/specs/2026-11-06-c-core.md section 2, gate 1). A case names its row in its DIFF column; that case is pinned by
its committed output only. Diagnostics on descriptor 2 are not compared with busybox: the core set's one form is
`TOOL: path: reason`.

| row | tools | native core set | busybox | why |
| --- | --- | --- | --- | --- |
| D-1 | all | an option outside the tool's set: `TOOL: not supported: -X`, status 2 | `TOOL: unrecognized option: X`, status 1, or the option's busybox-only meaning (`wc -L`) | gate 4: refusal by name, one status for a refusal |
| D-2 | `wc -w` | a word is a run of bytes that are not white space (POSIX XCU `wc`) | a word starts only on printable ASCII; other bytes neither start nor end one | POSIX; a UTF-8 word such as `é` counts |
| D-3 | all | a usage error (a missing operand or option value, a bad number): `TOOL: WHAT`, status 2 | the usage text or `TOOL: invalid number 'X'`, status 1 | one status for every error of the command line, as a refusal (gate 4); POSIX asks only for a status above 0 |
| D-4 | tools on `core/path.ci`'s walk (`find`, `du`) | walk order: a directory's names in byte order, the same on every file system and under Daphnis | the order readdir returns them | one transcript on Linux and Daphnis (gate 2); such a case is judged by its output records (lines, or NUL-ended) sorted, and its status (`tools/check-core.py` UNORDERED; no stale check) |
| D-10 | `ls -l` | owner and group as numbers (XCU `-l` names both; Daphnis has no user database), and a directory's list starts with `total N` | neither column (the oracle has no `FEATURE_LS_USERNAME`) and no `total` line | XCU `ls -l`; CORE-2's recommendation |
| D-11 | `ls -n` | a directory's list starts with `total N`, its blocks in 512-byte units | no `total` line | XCU `ls -n` |
| D-12 | the walk (`ls -R`, `du`) | past 256 nested directories: `TOOL: limit: DEPTH_MAX`, status 2 | goes on | gate 3: a named limit, never an unbounded stack (`DEPTH_MAX`, spec section 5) |
| D-13 | `head -n -N`, `head -c -N` | a usage error (the count is a positive decimal integer), status 2 | all but the last N lines or bytes | XCU `head`; no script in this tree uses the busybox form |
| D-14 | `tail -f` | refused by name on a pipe and with two or more FILEs, status 2 | on a pipe, ignores -f; with two FILEs, follows both | spec section 8: `-f` follows one regular file |
| D-15 | `stat` | an owner's and a group's name is `UNKNOWN` (Daphnis has no user database) | the name in the host's `/etc/passwd` and `/etc/group` | the names Daphnis can give; busybox under Daphnis prints `UNKNOWN` too |
| D-20 | `cp -R` | a target that is the source or lies inside it is refused whole: `cp: SRC: would copy into itself`, nothing made, status 1 | makes the target, copies all but the new copy itself (`recursion detected, omitting directory`), status 1 | no half copy to clean up; the refusal is known before the first byte moves |
| D-21 | `tee` | a FILE operand `-` is a file named `-` (POSIX XCU `tee`) | writes descriptor 1 a second time | POSIX |
| D-30 | `grep` | a back-reference (`\1` to `\9`): `grep: not supported: back-reference`, status 2 | matches by backtracking | CORE-3: every pattern runs in time linear in the line, so none can stall a desk |
| D-31 | `tr` | SET2's `[c*n]` and `[c*]` repeat c n times, or until SET2 is as long as SET1 (XCU `tr`) | the bytes `[`, `c`, `*`, `n`, `]` | POSIX |
| D-32 | `tr -C`, `sort -C` | XCU's `-C`: `tr` complements SET1 by byte, `sort` checks order silently (status 1 at the first disorder) | `tr` does not complement SET1; `sort` refuses it, status 2 | POSIX |
| D-33 | `cut -f` | a line with fewer fields than the list asks for ends at its last field (XCU `cut`) | adds a delimiter after it (`short:` for `-f1,7`) | POSIX; the bytes of the fields asked for, nothing else |
| D-34 | `sort -n` | a number is `[-]digits[.digits]` after blanks; anything else counts as 0 | read by strtod: `0x10` is 16 and `1e3` is 1,000 | XCU `sort -n`; Daphnis has no floating point (`-g` is refused, D-1) |
| D-35 | `grep -w` | an empty match counts at any place between two bytes that are not word bytes | only at the start of the line | the rule `-w` states, applied at every position, as for a match that is not empty |
| D-36 | `grep` | `[[.c.]]` and `[[=c=]]` name the one byte c (XBD 9.3.5 in the POSIX locale) | the oracle's regcomp (musl) refuses both: status 2 | POSIX |
| D-37 | `sha256sum -c`, `md5sum -c` | a line that is not `HEX  NAME` or `HEX *NAME` is said on descriptor 2 and makes the status 1; it names no file, so `-w` changes nothing | takes the text after its first space as a file name, which fails to open (`FAILED`) | a malformed list is an error of the list, not of a file |
| D-40 | `xargs -L`, `-x`, `-s` | `-L N` runs once per N lines, a line ended by a blank going on to the next (XCU); `-x` stops with `xargs: argument list too long`, status 1, when the size limit cuts a `-n` or `-L` batch short; `-s` above 65,536 is `xargs: limit: ARGS_BYTES`, status 2 | the oracle has no `-L` (status 1); `-x` is accepted and ignored; `-s` takes any size | XCU `xargs`; ARGS_BYTES is the size of the argument block (spec section 5) |
| D-41 | `find -size N` | N 512-byte blocks, a file's size rounded up to whole blocks (XCU): a 2-byte file is 1, an empty one 0 | the size divided by 512 rounding down, then compared one block off | XCU `find -size` |
| D-42 | `find -ok` | the prompt on descriptor 2 and the answer as a line from descriptor 0; no answer is no, the test false, status 0 | status 1 when standard input gives no answer | XCU `find -ok`; the answer read is the gate's input, never a terminal the case does not have |
| D-43 | `sleep` | `--` ends the options; exactly one operand, a second is a usage error, status 2 | `--` is an invalid number (status 1); operands are summed | XCU `sleep` (one operand; utility syntax guideline 10) |
| D-44 | `date` | `-d @N` for N from -62,135,596,800 to 253,402,300,799 (years 1 to 9,999, `YEAR` in spec section 5), negative N too; `%k`, `%N`, a `-` or width flag and a lone `%` are refused by name, status 2 | rejects N below 0 (status 1); goes on to year 0 and +10000; prints the GNU extensions or nothing | XCU `date` conversions only; a named limit (gate 3) |
| D-45 | `env` | the utility is found on the `PATH` of the new environment (musl's `execvp`), so `PATH=/nowhere echo` is not found, status 127 | prefers its own applet (`FEATURE_PREFER_APPLETS`) and runs `echo` | XCU `env`; the native set has no applets to prefer |
| D-50 | `test` | four arguments `( X Y )` are the two-argument test `X Y` (XCU `test`: `( -n x )` is true); the tool is cish's own `test` | a syntax error, status 2 | XCU; /bin/test and the shell's builtin give one answer (CT-5) |
| D-51 | `printf` | a floating conversion (`%f %e %g %a` and their capitals) is refused: `cish: printf: %f: not supported (no floating point)`, status 1 | prints the double | no floating point in Daphnis; the shell's builtin refuses the same |
| D-52 | `seq` | integers only: a fraction, an exponent or hex is a usage error (D-3), and every number up to 2^62 prints exact | reads each operand as a double, so `1.5` counts by halves and numbers past 2^53 print rounded | no floating point in Daphnis; checked I64 |
| D-53 | `seq` | an INCR of 0 is a usage error: `seq: zero increment`, status 2 | prints FIRST without end | gate 3: no unbounded run; no case, since busybox does not end |

| D-55 | `rev` | a NUL is a byte like any other and is reversed with its line | a line ends at its first NUL; the bytes after it are dropped | bytes in, the same bytes out, reversed |
| D-56 | `printf` | a conversion without its argument takes the empty string or 0 (XCU `printf`), status 0 | `printf: invalid number ''`, status 1 | XCU; the shell's builtin does the same |
| D-57 | `fetch` (BU-5a, in the place of CT-5's `wget`) | `-o FILE` for wget's `-O FILE`, always quiet; HTTP/1.1 with busybox wget's request bytes, chunked and `content-length` bodies, a short body is status 1; a status other than 2xx is `server returned error`, status 1, and a redirect is not followed; HOST is a dotted quad, `localhost` or a name asked of 10.0.2.3 (no `/etc/hosts`) | follows redirects, FTP, the resolver of the C library, a progress bar without `-q` | the HTTP client of the base image (SW-1 C); judged by check-core.sh's http lines against busybox-net through `tools/core-fetch-oracle.sh`, and by `check-net.sh` |
