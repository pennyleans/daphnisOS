# Hardware pages

One page per board Daphnis is measured or booted on. A page carries machine facts only: what the
firmware, the kernel and the buses report, with the file the answer comes from. No decisions, no
plans, no serial numbers, UUIDs, MAC or IP addresses, or user and host names.
